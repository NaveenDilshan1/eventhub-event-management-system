# Event Hub Pro

Event Hub Pro is a comprehensive event management platform designed to make organizing, ticketing, and managing events effortless.

## Features

- **Event Creation & Management**: Easily create and manage events with detailed information.
- **Ticketing System**: Secure ticket purchasing and management.
- **QR Code Check-in**: Streamlined attendee check-in using QR codes.
- **Admin & Staff Dashboards**: Dedicated interfaces for organizers and staff to monitor event stats and handle logistics.
- **Multi-role Access**: Support for Admins, Event Managers, Staff, and Attendees.
- **Global Currency & Settings**: Customizable platform settings including currency and branding.

## Tech Stack

- **Frontend**: React, TypeScript, Vite, Tailwind CSS, shadcn/ui, Framer Motion
- **Backend**: Node.js, Express
- **Icons**: Lucide React
- **Themes**: Light and Dark mode support

## Getting Started

### Prerequisites

- Node.js & npm installed

### Installation

1. **Clone the repository**:
   ```sh
   git clone <YOUR_GIT_URL>
   ```

2. **Backend Setup**:
   ```sh
   cd backend
   npm install
   npm run dev
   ```

3. **Frontend Setup**:
   ```sh
   cd frontend
   npm install
   npm run dev
   ```

## Development

The project uses a modern stack with Vite for fast development and hot module replacement. 

## Deployment

Deploy the frontend using platforms like Vercel or Netlify, and the backend using services like Heroku, Render, or a VPS.
