# 🎉 EventHub - Event Management System

A modern web-based event management platform designed to simplify event planning, organization, and participation. EventHub enables users to create, manage, and attend events with ease while providing powerful tools for administrators.

---

## 📌 Project Overview

EventHub is a full-stack web application that allows users to:

* Create and manage events
* Register and participate in events
* Generate and scan QR-based tickets
* Receive real-time updates and notifications
* Manage users and bookings via an admin dashboard

## ⚙️ Installation & Setup Guide

### 1️⃣ Clone the Repository

```
git clone https://github.com/NaveenDilshan1/eventhub-event-management-system.git
```

### 2️⃣ Navigate to Project Folder

```
cd eventhub-event-management-system
```

---

### 3️⃣ Setup Backend

```
cd backend
npm install
npm start
```

Backend will run on:
👉 http://localhost:5000 (or your configured port)

---

### 4️⃣ Setup Frontend

Open a new terminal:

```
cd frontend
npm install
npm start
```

Frontend will run on:
👉 http://localhost:3000

---

## 🔐 Environment Variables

Create a `.env` file inside the backend folder and add:

```
MONGO_URI=your_mongodb_connection_string
PORT=5000
JWT_SECRET=your_secret_key
```
